# Second Brain

Aquí guardo lo que voy aprendiendo: notas técnicas, proyectos, decisiones y una nota por día. Lo escribo en [Obsidian](https://obsidian.md) y lo subo a GitHub para tenerlo a mano y aprender en público.

Lo uso todos los días, así que siempre hay algo nuevo.

## Cómo está ordenado

Uso el método PARA de Tiago Forte. Cada nota va a una carpeta según qué tan cerca está de convertirse en acción:

| Carpeta | Qué hay |
|---|---|
| [`0-Inbox`](0-Inbox) | Lo que todavía no ordené |
| [`1-Projects`](1-Projects) | Proyectos con objetivo y fecha |
| [`2-Areas`](2-Areas) | Temas que sigo de forma permanente: carrera, aprendizaje, salud |
| [`3-Resources`](3-Resources) | Notas técnicas, snippets, resúmenes de cursos y libros |
| [`4-Archive`](4-Archive) | Lo que ya terminé o dejé de usar |
| [`Daily`](Daily) | Una nota por día: qué hice, qué aprendí, qué sigue |

## Por dónde empezar

- Para ver en qué ando, abre la última nota de [`Daily`](Daily).
- Para lo más útil, revisa [`3-Resources`](3-Resources).
- Si quieres copiar el sistema, las plantillas están en [`Templates`](Templates): nota diaria, proyecto, nota y decisión.

## Leerlo en Obsidian

1. Clona el repo: `git clone https://github.com/romanvarela-rgv/second-brain.git`
2. En Obsidian, elige "Open folder as vault" y selecciona la carpeta.
3. Activa los community plugins si quieres usar Obsidian Git.

La configuración de Obsidian viene incluida en `.obsidian/`, así que las plantillas y la nota diaria funcionan desde el primer momento.
